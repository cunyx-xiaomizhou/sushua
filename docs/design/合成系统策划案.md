> **阅读对象**：通用
> **系统定位**：独立物品工厂子系统，通过配方将材料转化为新物品，与外部系统解耦
> **依赖系统**：属性系统（`属性系统策划案.md`）— 产出装备时调用 `AttributeSystem.WriteBase()` 写入基础属性层

---

## 一、系统概述

合成系统是面向物品生产的工厂界面。玩家通过消耗材料和金币，按照配方制作新物品（装备/消耗品/材料等）。系统只负责"按配方把材料变成新物品"，不涉及强化、属性修改、装备穿戴，也不涉及配方的解锁/获取逻辑。

**核心体验关键词**：计划性制作 · 配方驱动 · 材料循环消耗

**打开方式**：主界面点击"合成"图标，或通过 NPC/工作台交互打开。

---

## 二、合成系统读取的配方字段

> 配方数据由外部配方系统管理（解锁条件、获取方式等均归配方系统）。合成系统**只读取**以下与合成执行直接相关的字段：

| 字段 | 说明 |
|------|------|
| ID | 配方唯一标识 |
| 名称 | 配方显示名（通常为产出物品名） |
| 分类 | 武器/护甲/饰品/消耗品 |
| 产出物品ID | 合成成功后产出的物品 |
| 产出数量 | 单次合成产出数量（默认1） |
| 材料需求列表 | 所需材料（物品ID + 数量）的数组 |
| 金币消耗 | 单次合成所需金币 |
| 产出品质 | 普通/优秀/稀有/史诗/传说 |
| 产出属性范围 | 装备类产出的基础固定属性区间（最小值~最大值） |
| 附加属性条数 | 由品质决定（详见属性系统策划案 第四章 基础属性层） |
| 附加属性池 | 该部位+品质可附带的普通/特殊属性候选 |
| 是否可合成 | 由配方系统计算后传入（已解锁=true，未解锁=false） |

> **注意**：解锁条件类型、解锁条件值、图纸获取等字段归配方系统所有，合成系统不感知这些字段，仅读取配方系统输出的"是否可合成"布尔状态。

## 三、品质体系

5 个品质等级，从低到高：普通、优秀、稀有、史诗、传说。品质决定以下维度（详见`属性系统策划案.md` 第四章 基础属性层）：

| 品质 | 基础固定属性数值范围 | 附加属性条数 | 可出特殊属性？ |
|------|:------------------:|:----------:|:------------:|
| 普通 | 50%~65% | 0 | ❌ |
| 优秀 | 60%~75% | 0~1 | ❌ |
| 稀有 | 70%~85% | 1~2 | ❌ |
| 史诗 | 80%~92% | 2~3 | ✅（权重低） |
| 传说 | 88%~100% | 3 | ✅（权重高） |

> 合成产出装备时，系统调用 `AttributeSystem.WriteBase()` 写入基础属性层：先生成基础固定三维（ATK/DEF/HP），再按品质随机附带普通/特殊属性。

## 四、配方分类

支持 5 种筛选分类：

| 分类 | 包含 |
|------|------|
| 全部 | 所有配方（可合成的排前，不可合成的灰显在后） |
| 武器 | 产出为武器类装备的配方 |
| 护甲 | 产出为防具类装备的配方 |
| 饰品 | 产出为饰品类装备的配方 |
| 消耗品 | 产出为药水、卷轴等消耗品的配方 |

---

## 五、材料体系

合成所需材料来源于背包系统，材料类型包括但不限于：

| 材料类型 | 获取途径 |
|---------|---------|
| 矿石 | 场景采集、关卡掉落 |
| 草药 | 场景采集 |
| 碎片 | 分解系统产出 |
| 精华 | Boss 掉落 |

> 合成系统不负责材料获取，仅读取背包中的材料持有量。图纸/配方解锁等归配方系统管理，不在合成系统范围内。

## 六、核心功能列表

| 功能 | 说明 |
|------|------|
| 配方列表展示 | 按分类展示所有配方，可合成的排前，不可合成的灰显在后 |
| 分类筛选 | 5个 Tab 按产出类型筛选配方 |

| 货币展示 | 顶部实时显示当前金币数量 |

## 七、用户操作流程

```
打开合成界面 → 选择分类 Tab → 浏览/选择配方 → 查看材料需求 → 确认合成 → 获得物品
```

### 7.1 浏览配方

- 左侧配方列表按分类筛选，每项显示产出物品图标+名称+品质底色
- 不可合成的配方灰显，可预览需求但不可执行合成

### 7.2 查看详情

- 选中配方后右侧展示：
  - 产出物品预览（图标+名称+品质+属性范围）
  - 材料需求列表（每项：图标+名称+持有量/需要量）
  - 金币消耗

### 7.3 执行合成

- 材料充足且配方可合成 → 合成按钮高亮可点击
- 材料不足或配方不可用 → 合成按钮灰显不可点击
- 点击合成 → 扣除材料和金币 → 播放合成动画 → 展示产出物品

### 7.4 交互规则

| 操作 | 结果 |
|------|------|
| 点击配方列表项 | 右侧展示该配方详情 |
| 点击分类 Tab | 筛选对应分类配方 |
| 点击合成按钮（材料足） | 执行合成，产出物品进背包 |
| 点击合成按钮（材料不足） | 按钮灰显，不可操作 |
| 点击不可合成配方 | 可查看详情，合成按钮灰显 |

## 九、系统边界

### 本期范围

- 读取配方配置表并展示
- 配方分类筛选
- 配方详情与材料校验
- 执行合成（扣材料+金币→产出物品）
- 产出装备属性生成（调用属性系统写入基础属性层）
- 合成结果反馈
- 货币展示

### 不在本期范围

- 物品强化/升级（归锻造系统）
- 属性修改/附魔（归附魔系统）
- 物品分解（归独立分解系统）
- 装备穿戴/对比
- 批量合成
- 配方管理（解锁/获取/学习等，归配方系统）
- 材料获取引导/跳转

### 对接方式

- 合成系统只读 RecipeConfigs（配方配置表）和背包材料数据
- 合成成功后调用 `AttributeSystem.WriteBase()` 生成装备的基础属性层（基础固定三维 + 附加属性）
- 产出物品写入背包，扣除材料和金币
- 系统不主动调用锻造/附魔等外部逻辑，**完全解耦**
