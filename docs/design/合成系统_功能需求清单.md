> **文档性质**：功能点清单 + 验收标准，不含技术实现细节
> **基于**：合成系统策划案 v1.0

---

## 1. 界面开关

### 1.1 打开合成界面
- 主界面点击"合成"图标 或 通过 NPC/工作台交互打开

**验收标准**：
- [ ] 点击后合成界面正常展示
- [ ] 有打开过渡动效

### 1.2 关闭合成界面
- 可通过关闭/返回方式关闭界面

**验收标准**：
- [ ] 界面关闭后恢复之前界面
- [ ] 有关闭过渡动效

---

## 2. 配方列表展示

### 2.1 配方列表
- 左侧以列表形式展示所有配方，可合成的排前，不可合成的灰显在后

**验收标准**：
- [ ] 打开界面后能看到配方列表
- [ ] 每个配方项显示产出物品图标、名称、品质背景色
- [ ] 可合成的配方正常显示，可选中
- [ ] 不可合成的配方灰显，可预览但不可执行合成
- [ ] 配方数量超出可视区域时可滚动查看

### 2.2 品质区分
- 配方项通过品质背景色区分产出物品的品质等级

**验收标准**：
- [ ] 5种品质（普通/优秀/稀有/史诗/传说）有各自的背景色，视觉可区分

---

## 3. 分类筛选

### 3.1 Tab 分类
- 支持 5 个分类 Tab：全部、武器、护甲、饰品、消耗品

**验收标准**：
- [ ] 默认选中"全部"
- [ ] 切换 Tab 后只显示对应分类的配方
- [ ] 当前选中的 Tab 有高亮区分

---

## 4. 配方选中与详情

### 4.1 选中配方
- 点击配方列表项选中，右侧详情区展示该配方信息

**验收标准**：
- [ ] 点击后列表项有选中态反馈
- [ ] 同时只有一个配方处于选中态
- [ ] 右侧详情区实时更新为选中配方的信息

### 4.2 详情面板 - 产出预览
- 展示选中配方产出物品的图标、名称、品质、属性范围

**验收标准**：
- [ ] 产出物品图标正确展示
- [ ] 显示产出物品名称和品质标签
- [ ] 装备类产出显示属性范围（如"攻击力 30~50"）
- [ ] 消耗品类产出显示使用效果描述

### 4.3 详情面板 - 材料需求
- 展示该配方所需的所有材料及数量

**验收标准**：
- [ ] 每种材料显示图标、名称、持有量/需要量
- [ ] 材料充足时数量显示为绿色
- [ ] 材料不足时数量显示为红色
- [ ] 金币消耗独立显示，不足时红色标注
- [ ] 材料数据与背包实际持有一致

### 4.4 不可合成状态
- 配方系统标记为不可合成的配方，详情区展示灰显状态

**验收标准**：
- [ ] 不可合成的配方选中后详情区可查看，但合成按钮灰显
- [ ] 不展示解锁条件（解锁逻辑归配方系统，合成系统不感知）

---

## 5. 执行合成

### 5.1 合成按钮状态
- 根据配方可用状态和材料持有量决定按钮状态

**验收标准**：
- [ ] 配方可合成 + 材料充足 + 金币充足 → 按钮高亮可点击
- [ ] 配方不可合成 → 按钮灰显不可点击
- [ ] 材料不足 → 按钮灰显不可点击
- [ ] 金币不足 → 按钮灰显不可点击

### 5.2 执行合成操作
- 点击合成按钮执行合成

**验收标准**：
- [ ] 点击后扣除对应数量的材料
- [ ] 点击后扣除对应金币
- [ ] 产出物品正确添加到背包
- [ ] 合成后材料持有量实时更新（详情面板数量刷新）
- [ ] 合成后金币数量实时更新
- [ ] 若合成后材料不足以再次合成，按钮自动变为灰显

### 5.3 合成结果反馈
- 合成成功后展示获得物品

**验收标准**：
- [ ] 合成成功有视觉动效反馈
- [ ] 弹出/展示获得物品的图标、名称、品质
- [ ] 有合成成功音效

---

## 6. 货币展示

### 6.1 金币显示
- 界面顶部显示玩家当前持有金币数量

**验收标准**：
- [ ] 显示金币图标 + 数量
- [ ] 数量与玩家实际持有一致
- [ ] 合成扣费后数值实时更新

---

## 7. 空态处理

### 7.1 无配方
- 当前分类下无可展示配方时

**验收标准**：
- [ ] 列表区域显示空态提示文案

### 7.2 未选中配方
- 未选中任何配方时的详情区状态

**验收标准**：
- [ ] 详情区显示提示文案（如"选择配方查看详情"）

---

## 8. 音效需求

### 8.1 音效事件

**验收标准**：
- [ ] 合成成功时有音效反馈
- [ ] 选中配方切换时有轻量音效
- [ ] 合成按钮不可用时点击有提示音效

## 系统边界（本期不做）

- 物品强化/升级（归锻造系统）
- 属性修改（归附魔系统）
- 物品分解（归独立分解系统）
- 装备穿戴/对比
- 批量合成
- 配方管理（解锁/获取/学习等，归配方系统，合成系统只读配方表的"是否可合成"状态）
- 材料获取引导/跳转
