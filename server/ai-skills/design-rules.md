# UI 设计规范 (00)

> 引擎无关规则集。数值、比例、交互行为为设计约束，具体实现由目标引擎映射。

## 第一章：全局规则

### 1.1 风格一致性与标签匹配（Rule 0 — 最高优先级）

**核心原则**：风格一致性优先于一切，宁少装饰也不混搭不同风格资源。同系列资源优先，识别后尽量全选同系列。

**风格关键词→Tag映射**：

| 用户描述 | Tag | 用户描述 | Tag |
|---------|-----|---------|-----|
| 二次元/动漫/anime | 二次元 | 奇幻/魔幻/fantasy | 奇幻 |
| 科幻/太空/赛博 | 科幻 | 写实/拟真 | 写实 |
| 国风/古风/仙侠 | 国风 | 暗黑/哥特 | 暗黑 |
| 卡通/Q版/可爱 | 卡通 | | |

不在表中则用原词搜索。未指定风格默认卡通。

**多风格匹配**（如"卡通科幻"）：优先同时含所有风格的资源；降级选单标签（优先主风格）。

**纹理多状态（Rule 3）**：同一控件需多种颜色状态时：①优先搜索配对纹理（同系列不同颜色）；②配对不足时用颜色叠加——亮色纹理着深色（如 RGB(0.3,0.3,0.35)），深色着亮色不推荐；③同组互斥按钮必须同一纹理+颜色叠加区分状态。

### 1.2 缩放与区域规则

**Slice9 规范**：边距 `round(纹理尺寸*0.42)`（40-45%范围）；显示尺寸≥纹理尺寸；按钮文字与切片同尺寸同位置+水平垂直居中。

**Scale 字段规则**：

| Scale | 约束 |
|-------|------|
| 等比例缩放 | 宽高比不变，禁止切片，**放大≤2倍** |
| 九宫格缩放 | 尺寸≥原图，边距42% |
| 三宫格左右 | 高度=原图高，上下边距=0，宽度可自由 |
| 三宫格上下 | 宽度=原图宽，左右边距=0，高度可自由 |
| 任意比例 | 无约束 |

### 1.3 文本与图标规则

**文本可读性（最高优先级）**：深色底→亮色字，浅色底→深色字。

- 亮色文字（深色底）：标题 RGB(0.95,0.92,0.85)+描边4~6px深色；正文 RGB(0.85,0.82,0.75)
- 深色文字（浅色底）：标题 RGB(0.15,0.1,0.05)无描边；正文 RGB(0.25,0.2,0.15)
- 按钮：黄/绿/浅色→深色字；灰/紫/深色→亮色字，始终描边3px反差色

禁止浅底亮字、深底深字。

**图标规范**：等比居中缩放，占容器75%，禁止拉伸。

### 1.4 视口适配与布局计算

- 监听视口变化重算布局，全屏内容完整不重叠
- 超出可视区域用滚动/分页
- 绝对坐标仅最外层，子控件靠锚点；布局值 `round()` 取整

## 第二章：组件规则

### 2.1 面板

**全屏面板**：占满视口，无关闭按钮；左上角返回箭头+右侧文本标题。
**弹窗面板**：不占满，居中+半透明遮罩；右上角X按钮80x80；尺寸≤视口80%。

### 2.2 按钮

**悬停/按下缩放**：悬停1.05/按下0.95/释放1.0，0.15s缓动。
**Slice9按钮**：容器、切片、文本、热区尺寸必须一致。
**核心CTA按钮**：主按钮暖色醒目（红/金/橙），次要按钮冷色调（灰/白/浅紫）。

### 2.3 卡片容器

将内容区域按比例切分为N个垂直分区，分区之间留间隔。

| 卡片类型 | 分区比例 | 间隔 |
|---------|---------|------|
| 关卡卡 | 15%/60%/20% | 2.5%×2 |
| 物品卡 | 55%/20%/20% | 2.5%×2 |
| 奖励卡 | 70%/25% | 5%×1 |

### 2.4 物品栏格子

**品阶底板**：优先同系列不同色底板，不足时白/灰白底板+颜色叠加。
**安全区**：内容约束在90%内；图标区=单元格*0.75居中；数量文字右下角。
**选中框**：Slice9叠加在格子上方，与底板同边距/尺寸/位置。
**底板单层**：物品卡片只允许一层底板纹理。

### 2.5 信息展示面板

**操作按钮锚定底部**：Y=`面板高-留白-按钮高`，水平居中。
**属性行**：文字在上(50%)，间隔(5%)，进度条在下(30%)。

### 2.6 进度条

**程序化绘制**：绘制圆角渐变矩形，两端保持圆角；数值标签为兄弟节点。

### 2.7 页签

**贴边方向**：左竖排→右贴边，右竖排→左贴边，顶横排→下贴边，底横排→上贴边。

## 第三章：自检清单（强制）

**A. 文本可读性**：深底文字RGB均值>0.7？浅底<0.3？
**B. 图标+文字对齐**：字体度量精确定位。
**C. Slice9规则**：三宫格/九宫格边距验证。
**D. 控件尺寸一致性**：按钮组容器/切片/文本/热区尺寸位置一致。
**E. 垂直分区**：分区不重叠，元素约束在分区内。
