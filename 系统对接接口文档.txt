# 粥粥速刷网

### 接口文档
在本文档中你将了解到本系统中所有的公开接口，这些接口均支持使用`uid`和`api_key`进行调用。

### 接口规范
所有接口均遵循以下格式返回：
```json
{
    "code": xxx,
    "msg": "xxx",
    "data": {...}/[...],
    "time": xxx
}
```
`code`为`200`是成功，其他均为失败，失败原因在`msg`中
出现php报错信息属于意外现象，请及时上报反馈
